script

The tools topic-hive documents the developer and operator scripts that live in the EmulatR V4 source tools/ directory. The shell scripts are deployed beside Emulatr.exe in <run-dir>/tools/ by the CMake POST_BUILD step and anchor to the run-dir root; the Python utilities run directly from the source tree. All shell scripts target Git Bash on Windows.

 

Most scripts locate the run-dir by anchoring to their own directory and expect Emulatr.exe, the firmware, and config/EmulatrV4.ini beside it. None of them build except where the name says so (build_test_run); the rest are run-only or diagnosis-only.

 

Build, run, and boot

build_test_run -- Rebuild (RelWithDebInfo), run the chipset halt-register doctest, then hand off to the OpenVMS boot.

run_fw.sh -- Launch a v7_3 firmware image with 4 GiB RAM for a chosen model; cold or warm boot.

launch_vms_boot -- Cold-boot DS10/EV6 and boot OpenVMS Alpha V8.2 from dqa1.

 

Diagnostics and tracing

diag_halt_irq4 -- IRQ4 / halt-gate runbook: arm a window retire trace and snapshot interrupt state from the console.

trace_halt -- Console-armed retire trace plus the TIG bring-up canary.

 

Trace analysis and profiling

analyze_retire_trace -- Find the dominant PC loop (the wedge body) in a retire-compact trace.

profile_resolve -- Annotate RetireProfiler dumps with SRM/PAL symbols and region rollups.

 

Firmware and disassembly

alpha_diasm -- Minimal Alpha (EV6) disassembler for reading PAL and console code by file offset.

decompile_ds10 -- Dump C source from an already-analyzed Ghidra project (headless, decompile-only).

 

Snapshots and disk images

snapmap -- Decode an .axpsnap and hex-map its header, chipset block, and HWRPB.

mkdisk -- Generate a raw, stamped, writable disk image for the dqa install target.

 

Acceptance gate

phase1 dispatch gate -- Prove the AlphaCpuAgent dispatcher boot is byte-identical to the legacy boot.
