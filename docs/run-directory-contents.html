Run-Directory Contents

An inventory of the run directory, out/build/<config>/ (for the beta the config is relwithdebinfo). This directory is the runtime root: Emulatr.exe and every relative path it resolves -- config/, firmware/, the platform manifests, tools/, and the trace/log/snapshot output dirs -- live here. The CMake POST_BUILD step creates the subdirectory layout and stages the shipped files on every build.

 

Beta zip = run directory minus firmware. The firmware images are licensed vendor blobs; the tester drops their own <model>_v7_3.exe into ./firmware/. The developer-only artifacts listed at the bottom are stripped before packaging.

 

Core runtime files (shipped)

File

What it is

Emulatr.exe

The emulator executable. The run directory is its working directory; all relative paths resolve from here.

run_fw.sh

The firmware launcher, staged to the run-dir root (beside the exe) so it can anchor to its own directory and launch the binary directly.

Qt6Core.dll

Qt 6 core runtime, deployed by windeployqt. Emulatr is a console app using QtCore + QtNetwork (no GUI module).

Qt6Network.dll

Qt 6 network runtime (the TCP SRM console listener).

icuuc.dll

ICU Unicode library that Qt6Core depends on; deployed alongside the Qt DLLs.

<model>_v7_3_platform.json

Platform device manifests (ds10 / ds20 / ds25 / es40 / es45). Host-agnostic description of the guest device tree; Machine resolves the one matching the firmware stem beside the exe. Edit with the Platform Editor.

 

Subdirectories

Directory

What it holds

config/

Runtime configuration: Emulatr.ini (the operator settings), disk_types.json, and dec_disk_media_types.tsv (storage reference data). Copied from source config/ by CMake.

firmware/

Firmware blobs the emulator loads at runtime (<model>_v7_3.exe). NOT shipped in the beta zip -- the tester supplies their own image here.

editors/

The Platform Editor: platedit_qt[.exe] (Qt GUI; Qt DLLs deployed beside it on Windows), platedit_tui, its schema/ + catalog/ data, and the webui/ prototype. See Platform Editor.

tools/

The deployed tool scripts (see Tools Script Reference).

documentation/

The rendered Help & Manual user guide, EmulatRGuide.pdf, staged by CMake POST_BUILD so it ships with the build and the redist package.

logs/

spdlog output, separate from the CPU trace. Created at build; populated at runtime.

traces/

Retire / breakpoint / profiler .trc captures and the per-run trace logs, written when a trace is armed.

trace/

Legacy per-run cpu_trace.log location (created for backward compatibility).

snapshots/

Saved-state files (.axpsnap): auto snapshots and the predig_* fast-forward anchors.

networkinformation/

Qt network-information plugin backends, deployed by windeployqt.

tls/

Qt TLS backend plugins, deployed by windeployqt.

 

Generated at runtime (not part of the shipped set)

File

What it is

<model>_diag_flash.rom

Per-run diagnostic flash / NVRAM image. A fresh one gives a clean cold boot with the OEM string cleared; regenerated as needed.

flash_backup_<ts>.rom

Timestamped backup of flash/NVRAM taken before a destructive flash operation.

putty_console_p<port>_<ts>.log

PuTTY console session capture from an attached terminal.

run_*_<ts>.log / fw_*_<ts>.out

Timestamped console/stderr tee logs written by the run scripts.

 

Developer-only artifacts (strip before packaging)

File

What it is

Emulatr.pdb

MSVC debug symbols for the RelWithDebInfo build. Useful for local crash analysis; large, and not required to run.

*.svlPV_functionAndLineHooks2

Software Verify (Performance Validator) instrumentation sidecars. Profiling artifacts, not runtime files.

dbgHelp.dll, symsrv.dll, BorDebug.dll

Debug/symbol-server helper DLLs used by the profiler and crash tooling; not needed for a plain run.
