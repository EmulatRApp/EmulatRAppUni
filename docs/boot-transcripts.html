Successful Boot to SRM (per platform)

Reference transcripts of a healthy boot to the SRM console prompt for each platform, so the testing teams have a known-good baseline to diff their own runs against. Two fields in the firmware banner (SROM Revision on Tsunami, ARC Console on ES40) emit uninitialized / binary bytes on a real boot; they are shown here as [unset -- binary] for ASCII fidelity, not literal console text.

 

DS10 (Tsunami, Virtual/ISP)

DS10 reaches the same P00>>> prompt reliably. A worked DS10 console session (examine / deposit) is in Example (Console) execution. A full DS10 show config capture will be dropped in below.

ES40 (Typhoon, Virtual/ISP)

A Virtual (ISP) boot. The (Silicon Mode) string in the console banner is the FIRMWARE build variant, NOT the EmulatR execution mode -- this run is Virtual/ISP. ES40 reaches P00>>> in Virtual mode; it does NOT yet reach the prompt under EmulatR Silicon Mode (see Known Gaps G-24). South bridge is the Acer Labs (ALi) M1543C at slot 5/0; the full firmware init log (heap / drivers / GCT-FRU / memory test) runs to the banner.
