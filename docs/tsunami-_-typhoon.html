Tsunami \ Typhoon

Tsunami is the DEC/Compaq 21272 core-logic chipset for 21264 (EV6) systems -- the memory controller and PCI host bridge for the DS10, DS20, and ES40. Typhoon is the higher-bandwidth variant of the same 21272 (a doubled Dchip population for twice the memory bandwidth), used on the ES40-class boxes. They share one programming model; EmulatR treats them as variants of a single chipset.

 

Typhoon is NOT the 21274. The 21274 is the separate Titan chipset (DS15/DS25/ES45). Some earlier material mislabeled the 21274 as "Typhoon" -- corrected 2026-06-16.

 

Components

•Cchip -- command/address, the memory array address registers (AAR0-3), per-CPU device interrupt mask/request (DIM/DIR), the MISC register (NXM capture, inter-processor interrupt request, arbitration), and the interval timer.

•Dchip -- the data slice; carries the chip revision (DREV).

•Pchip -- the PCI host bridge (sparse/dense memory, I/O, Type-0/1 config, DMA windows). Pchip0 is always present; Pchip1 is populated on the larger boxes.

•TIG -- the byte-wide Timer / Interrupt / GPIO bus that carries the front-panel halt / SMI status register (SMIR) and the per-CPU halt registers.

Memory above the Cchip AAR limit is non-existent memory (NXM) and raises a machine check. On the 21272 -- Tsunami and Typhoon alike -- the DS / ES40-class firmware encodes the array size in a 3-bit ASIZ (0x7 = 1 GB x 4 arrays), capping DRAM at 4 GB; the effective limit is the min of the Cchip PA width and the firmware ASIZ width. The 32 GB reach is a Titan (21274) property (its wider 4-bit ASIZ), NOT Typhoon -- see the Titan topic.

 

EmulatR model

Modeled by TsunamiChipset (chipsetLib/TsunamiChipset.{h,cpp}) with TsunamiCchip, TsunamiDchip, TsunamiPchip, and TsunamiTig. The variant (Tsunami vs Typhoon) is selected by model and latched at construction; the CSR layout, MMIO routing, and reset values live in Tsunami21272_CsrSpec.h / Tsunami21272_RegisterMap.h. The DS10 boots to the SRM >>> prompt on this model.

 

The Titan (21274) reuses these exact Cchip/Dchip/TIG register offsets and the same top-level PA map; the Titan-specific silicon is concentrated in the dual-port Pchip plus AGP. See the Titan topic.
