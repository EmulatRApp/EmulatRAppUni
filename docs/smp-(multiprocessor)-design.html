   SequentialDriver, ThreadedDriver  --|>  IExecDriver

 REFERENCES (N:1, NOT ownership):

   AlphaCpuAgent ...>  GuestMemory, TsunamiChipset, TraceSink

--------------------------------------------------------------------------------

 NOTES

   * Determinism boundary: per-CPU state is AGENT-owned; clock, arbiter, memory,

     chipset, trace are DISPATCHER-owned shared services (agent-referenced).

   * Execution policy is a swap behind IExecDriver -- SequentialDriver is the

     deterministic default; ThreadedDriver (barrier-synchronised) is opt-in.

   * TsunamiChipset is ~80% SMP-ready: per-cpuId arrays + MISC CPUID injection

     + read/write(offset,cpuId) overloads.

   * reservation fields migrate out of CpuState to a ReservationManager (Phase 3).

   * cpuSlot is default 0 today (single agent); STEP 4 sets it from agent id().
