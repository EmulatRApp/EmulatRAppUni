Building from Source

EmulatR is a CMake project built with MSVC (C++20). The build tree produces Emulatr.exe under out/build/<config>/, with the two configurations in active use being release and relwithdebinfo (the latter is the day-to-day debug / profiling build).

 

Configure the MSVC environment in bash:

 

base $ cd /d/EmulatR/EmulatRAppUniV4/Emulatr/out/build/release 

bash $ cd /d/EmulatR/EmulatRAppUniV4/Emulatr

 

cd /d/EmulatR/EmulatRAppUniV4/Emulatr/out/build/release

../../../tools/run_fw.sh ds20 cold        # or ./run_fw.sh ds20 cold if deployed

# look for:  platform latched: model=DS20 manifest=DS20 usedDefault=0 ocp40=Y ocp42=Y iic_acks=[ 0x40 0x42 ... ]

 

source tools/vsenv.sh

[vsenv] loading MSVC x64 env from: C:\Program Files\Microsoft Visual Studio\2022\Community

[vsenv] cmake : /c/Program Files/Microsoft Visual Studio/2022/Community/Common7/IDE/CommonExtensions/Microsoft/CMake/CMake/bin/cmake  (cmake version 3.31.6-msvc6)

[vsenv] ninja : /c/Users/tim/AppData/Local/Programs/Python/Python313/Scripts/ninja

[vsenv] cl    : present (MSVC x64)

 

 

cmake --build out/build/release -j        # build everything (Ninja, parallel)

 

 

cmake --build out/build/release -j --target Emulatr

cmake --build out/build/release -j --target Emulatr_tests

 

To build just the main target or the tests:

# resulting binary

./out/build/relwithdebinfo/Emulatr.exe

 

Generator: Ninja, supplied by the Visual Studio 2022 CMake and surfaced by tools/vsenv.sh. Dependencies: Qt and spdlog -- provision them before configuring; the CMake configure step resolves them. The canonical build is: source tools/vsenv.sh, then ./tools/build_emulatr.sh relwithdebinfo (or cmake --build out/build/relwithdebinfo -j), then run Emulatr_tests.exe.

 

Note: the diagnostic build flag EMULATR_MEMDIAG is a CMake option, not a runtime variable, and must stay OFF for normal use -- its per-instruction logging imposes roughly a 900x slowdown.

 

Advanced / diagnostic build recipes

The recipes below flip sticky CMake cache options (bring-up probes, IRQ diagnostics) or run ES40 hook / VPTB trace builds. They are for debugging only -- keep these OFF for a release build.

 

source ./tools/vsenv.sh

cmake -DEMULATR_IRQDIAG=ON .

grep -i irqdiag CMakeCache.txt        # want: EMULATR_IRQDIAG:BOOL=ON

./tools/build_emulatr.sh relwithdebinfo

 

cd /d/EmulatR/EmulatRAppUniV4/Emulatr && \

  TARGET=Emulatr_tests ./tools/build_emulatr.sh relwithdebinfo && \

  ./out/build/relwithdebinfo/Emulatr_tests.exe

 

cd /d/EmulatR/EmulatRAppUniV4/Emulatr && source tools/vsenv.sh && cmake -DEMULATR_BRINGUP_PROBES=OFF .

 

cd /d/EmulatR/EmulatRAppUniV4/Emulatr && ./tools/build_emulatr.sh relwithdebinfo

 

cd /d/EmulatR/EmulatRAppUniV4/Emulatr/out/build/relwithdebinfo && \

EMULATR_HOOKA_VA=0x600 \

EMULATR_2D_NOOP=1 EMULATR_SPINSKIP=1 \

./Emulatr.exe --firmware firmware/es40_v7_3.exe --mem 4294967296 \

  --no-autoload --max-cycles 0x50000000 2> es40_hooka.log

 

# the format for cmake on windows bash

 

cmake -DEMULATR_BRINGUP_PROBES=ON -DEMULATR_IRQDIAG=OFF .    # flip the sticky cache

cmake --build . -j        # or your build_emulatr.sh

cd /d/EmulatR/EmulatRAppUniV4/Emulatr/out/build/relwithdebinfo

EMULATR_VPTB_DIAG=1  EMULATR_HOOKA_CYC_FLOOR=280000000 \

  ./Emulatr.exe --firmware firmware/es40_v7_3.exe --mem 4294967296 \

  --no-autoload --max-cycles 0x50000000  2> es40_vptb2.log

grep -a "VPTB-DIAG\|ACVPROBE HOOKA" es40_vptb2.log | head -60

 

cd /d/EmulatR/EmulatRAppUniV4/Emulatr/

cmake -DEMULATR_BRINGUP_PROBES=ON -DEMULATR_IRQDIAG=OFF .

grep EMULATR_BRINGUP_PROBES CMakeCache.txt          # expect :BOOL=ON

cmake --build . -j                                   # or your build_emulatr.sh

strings Emulatr.exe | grep -c "ACVPROBE HOOKB"       # expect > 0 (probe is in the binary)

cd /d/EmulatR/EmulatRAppUniV4/Emulatr/out/build/relwithdebinfo

./Emulatr.exe --firmware firmware/es40_v7_3.exe --mem 4294967296 \

  --no-autoload --max-cycles 0x50000000  2> es40_hookb.log

grep -a "ACVPROBE HOOKB" es40_hookb.log

 

# 1. probes OFF for release (they ballooned the log to 5.2 GB)

cd /d/EmulatR/EmulatRAppUniV4/Emulatr && cmake -DEMULATR_BRINGUP_PROBES=OFF . && \

# 2. tests green

TARGET=Emulatr_tests ./tools/build_emulatr.sh relwithdebinfo && ./out/build/relwithdebinfo/Emulatr_tests.exe

# 3. boot gate: DS10/DS20 still reach >>> (align ini model per firmware); ES40 = "SCB halt cleared, no regression"
