mkdisk

Raw disk-image generator for the emulated ATA fixed disk (the dqa install target). It creates a blank, writable, raw flat disk image with 512-byte sectors by default. One artifact serves two roles: the read-proof target (so a read of LBN 0 returns verifiable bytes) and the empty install target the OS installer writes onto. It does not synthesize a bootable OS or a filesystem.

 

Usage

python tools/mkdisk.py dqa0.img --type EMULATR-DISK-4G

python tools/mkdisk.py data.img --size 9G --sector 512

python tools/mkdisk.py dqa0.img --verify

 

Sizing and stamping

Size comes from --type (a config/disk_types.json catalog key mapping to total_sectors) or --size (K/M/G/T, 1024-based). The image is sparse where the filesystem supports it. With --stamp (the default) the first --stamp-sectors low LBNs plus the last sector get a 32-byte header (magic, LBN, FNV-1a checksum) so a read can be proven to return the correct LBN. Output is deterministic: identical arguments produce identical bytes. --verify checks the stamps instead of creating.
