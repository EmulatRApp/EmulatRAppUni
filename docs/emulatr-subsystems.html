Logging Subsystems (EmulatR)

EmulatR routes its diagnostic output through a small set of named subsystems. Each is the <subsys> argument accepted by the logging command-line options: --log-disable, --log-only, --log-verbose, and --log-file. Names are case-insensitive (Cbox, cbox, and CBOX all match). The facility is compiled in only when the binary is built with EMULATR_DIAGNOSTIC_LOGGING=ON; otherwise these options have no effect.

 

Subsystem

Default Throttle

What It Logs

Cbox

Loud-then-summary

EV6 Cbox (cache / system-bus interface) events -- the C_DATA / C_SHFT register chains, error registers, and MCHK-related Cbox polling.

Unalign

Loud-then-summary

Unaligned load/store emulation -- the fix-up path for misaligned memory accesses.

IntervalTimer

Loud-then-summary

Cchip interval-timer / clock-tick diagnostics -- tick scheduling and timer-interrupt delivery.

Snapshot

Unthrottled

Machine-state save / restore -- one line per .axpsnap save or load.

PalRelocation

Unthrottled

PALcode base relocation during cold boot -- the palBase move (one-shot per boot).

ChipsetCsr

Loud-then-summary

Tsunami / Titan chipset CSR accesses -- Cchip / Dchip / Pchip / TIG control & status register reads and writes (heavy during hardware bring-up).

StepD

Unthrottled

The SRM firmware-load "Step D" relocation step (one-shot per cold boot).

Misc

Loud-then-summary

Default catch-all for diagnostic streams without a dedicated subsystem.

 

Throttle Policies

Each subsystem has a default throttle that bounds how much it emits to stderr. The default-on policies keep a long run readable while still surfacing the first events.

Unthrottled - every event is emitted.

Loud-then-summary – the first 16 events emit in full, then one INFO heartbeat per 256K events.

Loud-then-mute – the first 32 events emit, then the subsystem goes silent on stderr.

Off – never emits to stderr (a configured file sink may still receive writes).

--log-verbose <subsys> forces a subsystem to Unthrottled; --log-disable <subsys> turns it Off; --log-only <csv> turns everything Off except the listed subsystems.

 

Examples

./tools/run_ds10.sh -- --log-only ChipsetCsr,Cbox

./tools/run_ds10.sh -- --log-disable IntervalTimer

./tools/run_ds10.sh -- --log-verbose Snapshot

./tools/run_ds10.sh -- --log-file ChipsetCsr=traces\csr.log
