IDE Devices

On the DS10 / DS20 (Tsunami) the CY82C693 provides the IDE controller, exposed on PCI bus 0, slot 5, function 1 ("Cypress 82C693 IDE" in show config). The primary channel is the dqa device path, the secondary is dqb. IDE register / port behavior (the 0x1F0-0x1F7 primary and 0x170 secondary blocks, plus PCI config) and absent-slave probing are shared across the controllers.

 

ES40 -- ALi M1543C / M5229

The ES40 (Typhoon) uses the ALi M1543C south bridge, whose IDE function is the M5229 (device id 0x5229). EmulatR wires the faithful ALi M5229 for ES40 / ES45 / DS25 via the SAME south-bridge lever (m_southBridge) that selects the ISA bridge, so bridge and IDE stay consistent by construction; DS10 / DS20 wire the Cypress instead. Both controllers wrap the shared ATA taskfile engine, which answers IDENTIFY on the dqa0 and dqb0 channels. Full show dev enumeration of dqa0 / dqb0 in silicon mode is active device-enumeration work (see Current Development Status).
