Command Line Options (EmulatR)

The launch scripts (tools/run_<model>.sh) pass these command-line options (qualifiers) through to the emulator -- supply them after a bare --. Options are parsed left to right; a command-line value overrides the corresponding setting in EmulatrV4.ini (CLI > ini). Flags use a double dash and take the next argument as their value.

 

Usage:

./tools/run_<model>.sh -- [options]

The launch script selects its model's firmware image automatically; to override, pass --firmware <path> after the --, or rely on the [ROM] firmwareImage entry in EmulatrV4.ini.

 

Configuration precedence

Settings resolve in this order, later winning: built-in defaults, then EmulatrV4.ini, then the command line -- so CLI > ini. Environment variables (EMULATR_*) are a SEPARATE, orthogonal layer: most are ENV-only diagnostic / trace toggles with no CLI or ini equivalent (see Environment Variables). The two that overlap a CLI flag -- --no-autoload / EMULATR_NO_AUTOLOAD and --autosnapshot / EMULATR_AUTOSNAP -- are combined so either source can set them, rather than one overriding the other. A single unified order (ini < CLI < ENV, ENV winning) is planned but NOT yet in effect (Known Gaps G-25). For run examples, background/detached execution, and the tools/ .sh helpers, see Running EmulatR from the Shell.

 

Command Line  / Qualifier

Description

--firmware <path>

Firmware image to load (raw binary or SRM .exe). Required; if omitted, falls back to [ROM] firmwareImage in EmulatrV4.ini.

--firmware-format <auto|raw|srm>

Loader contract. Default auto: picks srm for a .exe whose signature matches, raw otherwise.

--load-pa <hex|dec>

Physical address to load the image at. Default 0x0 for raw, 0x900000 for srm.

--start-pa <hex|dec>

Physical address to start execution at; the low bit is the PALmode bit. Default 0x0. Ignored for srm format (entry comes from the descriptor).

--mem <bytes>

Guest memory size in bytes. Default 64 MiB. Overrides [System] memorySize in the ini.

--max-cycles <N>

Cap on the run loop (hex or decimal). Default unlimited.

--autosnapshot <on|off>

Periodic auto_*.axpsnap saves. Default on. Off writes only the named --snapshot-on-pc file (use for cold-boot mint runs). Env equivalent: EMULATR_AUTOSNAP=off.

--no-autoload

Skip autoload-newest at startup, forcing a genuine cold boot instead of restoring the newest snapshot. Env equivalent: EMULATR_NO_AUTOLOAD=1.

--pal-mode

Force PALmode = true regardless of the --start-pa low bit.

--trace <dec,machine>

Enable the DEC-listing and machine-parsable trace channels (PAL-window + retire-compact). Argument is the two output paths, comma-separated.

--snapshot-on-pc <pc>[,<pc>...]

One-shot snapshot trigger(s): the first retire at each PC writes a predig_*.axpsnap. A single PC also disables auto-save so the file stays mtime-newest for autoload; a comma-list mints several (pair with --autosnapshot off). predig_ files are never pruned.

--snapshot-name-tag <s>

Base tag inserted after predig_ (e.g. gctbuild). With multiple PCs, _<pchex> is appended per file. Default: the hex PC.

--inject-interrupt-at-cycle <N>

EXPERIMENTAL. Fires a one-shot synthetic INTERRUPT-class trap when the cycle count first reaches N. 0 = off (default).

--dump-disasm <pa>:<count>

One-shot disassembly of <count> 4-byte instructions starting at physical address <pa>, dumped after firmware load and before run. Requires EMULATR_PA_DUMP=ON at build time.

--log-disable <subsys>

Silence one logging subsystem entirely.

--log-only <csv>

Silence every subsystem not in the comma-separated list.

--log-verbose <subsys>

Unthrottled emit for one subsystem.

--log-file <subsys>=<path>

Redirect one subsystem's emit stream to a file. Subsystems: Cbox, Unalign, IntervalTimer, Snapshot, PalRelocation, ChipsetCsr, StepD, Misc (case-insensitive). Requires EMULATR_DIAGNOSTIC_LOGGING=ON at build time.

--help

Print the usage/help text and exit.

 

Exit Codes

0  CPU halted cleanly (CALL_PAL HALT).   1  Any other stop (fault, max cycles, parse error).   2  Firmware load failure.
