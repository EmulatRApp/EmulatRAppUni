82077 Floppy Controller

EmulatR models a minimal Intel/DEC 82077AA-class floppy disk controller (FDC) at the legacy ISA base 0x3F0. Its purpose is firmware enumeration, not data transfer: it lets the SRM floppy probe for dva0 reset, initialize, recalibrate, and detect an empty drive so the powerup option-firmware scan concludes "no media" and proceeds, rather than stalling to a retry timeout. It is deliberately NOT a working floppy -- there is no media, no DMA engine, and no real sector transfer (see Limitations).

The 0x3F0 register window is reached through the FDC37C669 Super-I/O, which forwards non-config accesses (and the 0x536 poll register) to the embedded FDC. Command completion is signalled on ISA IRQ6, fed into the 8259 PIC by the chipset.

Completion and Interrupt Model

 

The 82077 has two command-completion mechanisms; conflating them desyncs the controller, so the model branches on them:

Path A -- no result phase, cleared by SENSE INTERRUPT STATUS: RECALIBRATE (0x07), SEEK (0x0F). The command asserts IRQ6 and sets the interrupt-pending flag; the driver then issues SENSE INTERRUPT (0x08) to read ST0/PCN and clear it.

Path B -- 7-byte result phase, cleared by READING the result phase: READ DATA, READ ID, WRITE DATA, and the other data commands. The command asserts IRQ6 and pushes 7 result bytes (ST0,ST1,ST2,C,H,R,N); the interrupt clears when the host reads the last result byte from 0x3F5, NOT via SENSE INTERRUPT.

 

ISA IRQ6 is edge-triggered, so the model maintains three interrupt edges precisely (these were the fixes that let the option-firmware scan complete instead of timing out):

1. Reset-completion IRQ -- deasserting /RESET (DOR bit 2, 0->1) raises IRQ6, the completion interrupt enable_controller waits on.

2. Command-busy deassert -- accepting a command opcode clears the pending interrupt (controller goes busy), so the command's completion re-asserts it as a fresh 0->1 edge. Without this a second IRQ-raising command (e.g. RECALIBRATE after the reset IRQ) would set an already-high line, produce no edge, and the driver's wait would hang to its timeout.

3. Path-B result-drain clear -- reading the final result byte clears the interrupt for result-phase commands.

The pending interrupt is visible two ways: as the 0x80 bit at the 0x536 polled register (polled-mode driver), and as the ISA IRQ6 line into the 8259 PIC (interrupt-mode driver), driven by the chipset's device-IRQ evaluation. SENSE INTERRUPT (0x08) and a controller reset clear it.

 

Configuration and Wiring

Base port 0x3F0; the FDC owns 0x3F0-0x3F5 and 0x3F7 (0x3F6 is IDE). These ports, plus the 0x536 poll register, are registered to the FDC37C669 Super-I/O, which forwards non-config-mode accesses to the embedded 82077. The chipset feeds the FDC's pending-interrupt line into the 8259 as ISA IRQ6 alongside the other ISA sources. A controller reset is driven by the DOR bit-2 /RESET line.
