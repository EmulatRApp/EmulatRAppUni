Appendix DS20 / ES40 / ES45

The larger multi-CPU machines. DS20 is modeled and boots to the SRM >>> prompt; ES40 is in active bring-up (Typhoon variant + ALi M1543C south bridge + silicon-mode path); ES45 (a Titan box) has its firmware decompressing but is not yet driven to the prompt. This appendix records each platform's current status and manifest.

 

DS20

Modeled and validated to the SRM >>> prompt. DS20 is a Tsunami box that wires the Cypress CY82C693 south bridge (like the DS10) and boots the SRM console. Run with [System] model=DS20.

 

ES40

In active bring-up. ES40 is a Typhoon (21272) box: EmulatR models the Typhoon chipset variant, the ALi M1543C south bridge with the M5229 IDE, and a silicon-mode boot path. Recent work landed the TIG module-reset model and the entry-snapshot boot acceleration. Run with [System] model=ES40 and firmware es40_v7_3.exe; see the ALi M1543C and ES40 TIG Module Reset topics.

 

ES45

Planned. ES45 (EV67 / 21264A) is a Titan (21274) box with the ALi M1543C south bridge; its compressed firmware (es45_v7_3.exe) decompresses correctly via the host oracle, but the Titan chipset and device modeling around it is not yet driven to the prompt. Manifest es45_platform.json is scaffolded.

 

Note that the compressed firmware oracle work (host_decompressor) was developed against es45_v7_3.exe, so the ES45 firmware image decompresses correctly even though the full platform is not yet driven; what remains is the device and chipset modeling around it.
