diag_halt_irq4

2026-06-14 runbook that disambiguates the IRQ4 / halt gate: World A (a clr_irq* write clears a real interrupt source) versus World C (the code is modelling a source read). Diagnosis only -- no rebuild. Deployed to <run-dir>/tools/ by CMake POST_BUILD; anchors to the run-dir root.

 

Environment

Sets EMULATR_TRACE_WINDOW=1 (required -- builds the window-only retire sink; arming is a no-op without it) and EMULATR_TIG_TRACE=1 (a canary that logs any access to an unmodeled TIG-window register).

 

Operator steps at the >>> prompt

1) Snapshot the interrupt state:

e pmem:801a0000300 -- Cchip DRIR

e pmem:801a0000280 -- Cchip DIR0

e pmem:80130000040 -- smir (expect 0)

2) Arm the retire trace with a READ to pmem:80130000FF8 -- it must return 7FFFFFFFFFFFFFFF; a deposit to that PA disarms.

3) Boot: b dqa1

4) Stop cleanly from a second Git Bash to flush the _srm.trc: touch <run-dir>/EMULATR_STOP

 

Triage

After the graceful stop the script greps the log for the TIG canary, HALTPROBE, and halt lines, then surfaces the TIG (0x80130xxxx) and Cchip (0x801a0xxxx) accesses and the last retire lines from the newest _srm.trc.
