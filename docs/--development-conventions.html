Development Conventions

The standing conventions for working in the EmulatR tree. The file-placement rules are also encoded as Cowork skills so an assistant follows them automatically; the source rules are enforced by review and the MSVC build.

 

Scripts and output files

•Runnable shell scripts live in EmulatRAppUniV4/Emulatr/tools -- never the repo root or a build directory. (Skill: emulatr-bash-scripts.)

•Run and console logs go in the run directory's ./logs; execution / retire / CPU traces go in ./traces (plural) -- never loose in the run-dir root. (Skill: emulatr-log-trace-placement.)

•Name every log / trace artifact <purpose>_<YYYYMMDD>_<HHMMSS>.<ext> so runs sort chronologically and never collide.

 

Source files

•ASCII(128) only in all file content -- no smart quotes, em dashes, Unicode arrows, or box-drawing glyphs in source, comments, docs, or generated artifacts. The MSVC pipeline expects unformatted ASCII.

•A copyright / attribution header on every generated source and header (and Markdown specs as an HTML comment), per ADR-0001; the template is docs/notes/templates/header_cpp.txt. No "small file" exemption.

•Include guards, never #pragma once. Pattern #ifndef <DIR>_<FILE>_H (e.g. PIPELINELIB_PIPELINEDRIVER_H). Qt MOC plus #pragma once under MSVC /permissive- causes LNK2001.

•Hex radix for all switch / case dispatch labels; convert decimal to hex by VALUE (16 -> 0x10, never digit substitution).

 

C++ and tests

•doctest: use CHECK only, never REQUIRE -- exceptions are disabled in V4.

•Never name an enum's printable helper toString (doctest ADL clash) -- use <typeName>Name(T) plus operator<<.

•Mark guessed IPR / SCBD values _PROVISIONAL and HRM-verify them before any HW_MFPR / MTPR decode matches them, or silent PAL corruption follows.
