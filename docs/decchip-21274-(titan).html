DECchip 21274 (Titan)

Titan is the DECchip 21274 core-logic chipset -- the memory controller and PCI/AGP host bridge for the 21264A/21264B (EV67/EV68) machines: the DS15, DS25, and ES45. It is the successor to the 21272 (Tsunami) and a separate part.

Naming: 21272 = Tsunami, 21274 = Titan. "Typhoon" is a 21272 variant, not the 21274. EmulatR's enum was corrected on 2026-06-16 so that DS15/DS25/ES45 map to the Titan variant.

 

Shared with the 21272

The most important architectural fact for EmulatR: Titan shares the top-level physical-address map and the Cchip/Dchip/TIG register offsets with the 21272. Cchip is at 0x801_A000_0000, Pchip0 at 0x801_8000_0000, Pchip1 at 0x803_8000_0000, hose stride h<<33. The Cchip MISC register is at +0x80 and the per-CPU device-interrupt requests DIR0-3 at +0x280 / +0x2C0 / +0x680 / +0x6C0 (confirmed against the ES45 Service Guide Appendix D). EmulatR therefore reuses TsunamiCchip, TsunamiDchip, and TsunamiTig unchanged.

 

New Titan silicon

•Dual-port PA-chip. Each of the two PA-chips has a G-port (PCI) at port offset +0x000 and an A-port (AGP) at +0x1000, each with four DMA windows (WSBA/WSM/TBA) and a port-control register (GPCTL/APCTL). This replaces the 21272's single-port Pchip.

•Richer error set. SERROR / GPERROR / APERROR / AGPERROR (plus enable/set companions) replace the 21272 single PERROR.

•AGP. Hose 2 (pachip0.A) and hose 3 (pachip1.A) are AGP; APCTL carries the AGP rate/SBA/enable/present bits.

•Four hoses. 0 = pachip0.G, 1 = pachip1.G, 2 = pachip0.A, 3 = pachip1.A; pachip1 presence is advertised in Cchip CSC bit 14.

 

EmulatR model (scaffold)

Implemented adjacent to the Tsunami model:

•Titan21274_CsrSpec.h -- authoritative constants (bases, Cchip/Dchip/Port offsets, PCTL/WSBA/error masks, hose map, machine-check vectors). Verified by static_assert.

•TitanPchip.h -- the new dual G/A-port PA-chip with reset window programming. Compiles and runs.

•TitanChipset.h -- top-level scaffold composing the reused Cchip/Dchip/TIG plus the Titan Pchip and the 4-hose interrupt mapping.

 

Status: scaffold, not yet a boot target. Faithful: all register offsets/identities, the interrupt/IPI/halt path (via the reused Cchip/TIG). Stubbed: per-hose PCI MEM/IO/config routing (TODO titan-pci-route, identical to the 21272 -- delegate to the Tsunami routing) and the ISystemBus + device layer (TODO titan-isystembus, mirror TsunamiChipset). Authoritative reference: Linux core_titan.c/.h and the ES45 Service Guide EK-ES450-SV Appendix D. Full detail in journal 20260616_titan_21274_interface.md.

 

CPU note

The Titan boxes run EV67/EV68 (21264A/B). The instruction set is essentially the same as EV6 for emulation purposes, so the CPU core is not the gap -- the chipset is. The ES45/DS25/DS15 south bridge is the ALi M1543C (shared with the ES40).
