DE500 Ethernet (21143 Tulip)

EmulatR models a DEC DE500-class Fast Ethernet adapter built on the DECchip 21143 ("Tulip") PCI Ethernet MAC. This topic documents Phase 1: the CSR register file, software reset, serial-ROM (SROM) station-address readout, and the CSR5 status register. Phase 1 is bring-up scaffolding for firmware and OS enumeration -- it presents a correct PCI identity and a readable station (MAC) address so the SRM device probe recognizes the adapter, but it is deliberately NOT a working NIC: there is no transmit/receive datapath, no descriptor-ring DMA, and no PHY/SIA link yet (see Phase Roadmap and Limitations).

The adapter is declared in the platform catalog as de500_tulip (systemLib/PlatformConfig.cpp) at PCI hose 0, bus 0, slot 7, function 0, interrupt pin INTA. Prior to Phase 1 the catalog entry was a config-space-only PciModel::Generic shell; Phase 1 adds the behavioral CSR model behind the same PCI identity.

Note: identity, class code, and BAR sizes in the catalog are marked _PROVISIONAL and should be reconciled against a hardware dump; the Phase 1 columns below reflect the intended scaffolding and are to be confirmed against the landed implementation.

CSR12-CSR15 are the 21143 SIA (Serial Interface Adapter) block that drives the on-chip 10/100 media interface. Phase 1 stores them and returns reset values; no link state is modeled.

 

Software Reset (CSR0 SWR)

Writing 1 to CSR0 bit 0 (SWR) issues a software reset. The bit is self-clearing: the model clears it and restores every CSR to its power-on default, re-primes the SROM read state, and returns CSR5 to its idle value. A PCI reset or device power-on performs the same restoration. The specific reset default values are _PROVISIONAL and should be confirmed against the implementation.

 

Serial ROM (SROM) and Station Address

The 21143 reads its configuration and 6-byte IEEE 802.3 station (MAC) address from an external 93C46-class serial EEPROM, accessed by bit-banging CSR9. Phase 1 models the SROM as a 128 x 16-bit (256-byte) image in the DEC SROM format; firmware clocks a read command and word address out through CSR9 and shifts the returned data back in one bit per clock.

SROM image layout (DEC format, offsets _PROVISIONAL -- confirm against implementation): an 18-byte header, an SROM format-version byte, the 6-byte station address near offset 0x14, one or more controller info-leaf blocks describing the media, and a CRC in the final two bytes.

CSR9 read-protocol bit roles (exact positions _PROVISIONAL): serial-ROM chip select, serial clock, data-in, data-out, plus the SROM/MII select and read/write strobes. The MII management side of CSR9 is not exercised in Phase 1.

The Phase 1 default station address is TBD (confirm; a DEC OUI 08-00-2B prefix is typical for DE500-class parts). Whether the address is fixed or configurable is an implementation choice to be recorded here once landed.

Phase Roadmap and Limitations

Phase 1 (this topic) -- CSR register file, software reset, SROM station-address readout, and CSR5 status. This is enough for firmware and OS to enumerate the adapter and read its MAC; it is identity and bring-up only.

Not yet modeled -- transmit/receive descriptor-ring DMA, actual packet movement, CSR6 operating-mode effects, SIA/PHY link negotiation, MII management, interrupt generation, and any host network backend. These are deferred to later phases and will be documented here as they land.
